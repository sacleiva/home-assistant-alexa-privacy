# Privacy Policy – Home Assistant Alexa Integration **Last updated: October 30, 2026** This application is a personal integration between Amazon Alexa and a privately operated Home Assistant installation. ## Information Collection This integration may process voice responses, commands, and interaction data required to provide voice-controlled functionality. It does not operate an independent database or collect personal information for advertising or commercial purposes. ## Information Usage Information processed by the integration is used exclusively to: - Receive and process Alexa voice responses. - Communicate with the user's Home Assistant installation. - Execute actions explicitly requested by the user. ## Information Sharing Personal information is not sold, rented, or shared with third parties for advertising purposes. Amazon Alexa and related Amazon services may process information according to their own privacy policies. ## Data Storage and Security The integration communicates with the user's privately operated Home Assistant installation. Authentication credentials and access tokens are intended to remain private. ## Contact This application is intended for personal, non-commercial use. For privacy-related questions, please contact the application owner through their GitHub account.
